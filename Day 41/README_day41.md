# Day 41 — Introduction to HTML

Day 41 of **Dr. Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp** marked the transition from Python into web development.

This day introduced the fundamentals of **HTML (HyperText Markup Language)** and focused on using HTML elements to structure and display content on a webpage.

## What This Day Covers

- HTML fundamentals
- HTML document structure
- Headings
- Paragraphs
- Horizontal rules
- HTML elements and tags
- Void elements
- Basic page structure
- Creating simple webpages
- Structuring content with heading hierarchy

## Projects & Exercises

### Heading Element

The first exercise introduced HTML headings and the different heading levels:

```html
<h1>Heading</h1>
<h2>Subheading</h2>
<h3>Section</h3>
```

The exercise demonstrated how heading levels create a hierarchy within a webpage.

### Paragraph Element

The paragraph exercise introduced the `<p>` element for displaying blocks of text.

It also demonstrated how multiple paragraphs can be organized within an HTML document.

### Void Elements

The void-element exercise introduced HTML elements that do not require a closing tag.

Examples include:

```html
<hr>
<br>
```

The exercises demonstrated how these elements affect the structure of page content.

### Movie Ranking Project

The main project for the day was a simple movie-ranking webpage.

The page contains:

- A main heading
- A subheading
- A horizontal rule
- Three movie entries
- A heading for each movie
- A short description for each movie

The completed version uses HTML headings and paragraphs to create the page structure.

For example:

```html
<h1>The Best Movies According to Mahad</h1>
<h2>My top 3 movies of all-time.</h2>
<hr>
```

Individual movie sections are then structured using `<h3>` and `<p>` elements.
