# 100 Days of Code — Python

This repository documents my progress through **Dr. Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

I use it as a record of my development in Python, including course exercises, independently built projects, refactored implementations, and larger projects as the course progresses.

## How I Approach the Course

For most projects, I try to:

- Read the project requirements first
- Build the project independently before watching the solution
- Use documentation and Google when I need to learn a function, method, or concept
- Refactor once the program works
- Compare my implementation with the course solution afterward
- Focus on understanding, problem-solving, structure, and readability rather than simply reproducing tutorial code

## What This Repository Contains

The repository includes a mixture of:

- Python fundamentals and small exercises
- Turtle and GUI-based projects
- Object-oriented programs
- Multi-file applications
- Games
- Automation projects
- Data-related projects
- Web development exercises
- More advanced Python applications as I progress through the course

Each project is organized within its own folder, making the repository itself the main record of what I have completed.

## Current Focus

At this stage, I am primarily focused on strengthening:

- Python fundamentals
- Problem-solving
- Object-oriented programming
- Program structure
- Refactoring
- Debugging
- Event-driven programming
- Working across multiple modules and files

As I progress, this repository will expand into areas such as **automation, web development, data science, APIs, databases, and more advanced Python applications**.

## Purpose

The goal of this repository is not just to complete the course, but to document how my programming improves over time.

Where possible, I attempt projects independently before viewing the instructor's implementation so I can develop my own problem-solving habits and then compare different approaches afterward.
